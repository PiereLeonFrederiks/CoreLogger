Add Lithological Layer/Unit
?

Log one lithological layer or unit: give it a depth range, primary soil type (with optional subsoil components and genesis — these build the KA5 short code automatically), and a free-text description. Turn on Gradual shift if the soil blends into a different type by the base of the layer, and Use Munsell colours to pick from a standardised colour chart instead of the default palette. Layer condition (disturbed / reworked, sediment gap / missing, anthropogenic) isn't set here — it's detected automatically from Finds & Observations once the layer exists.

Mark coring-induced disturbance intervals.

?

Mark depth intervals affected by coring-induced disturbance (e.g. piston corer, Rammsonde) — distinct from genuine sedimentary structures. Use Disturbed / reworked or Sediment gap / missing to flag a stratigraphic condition of the layer itself; any other type here just logs a coring artefact. A layer's condition badge is derived automatically from whichever of these overlap its depth range.

Mark sedimentary structure/fabric (banded, laminated, mottled…).

?

Log the physical fabric of the sediment itself — banding, lamination, grading, speckling and similar — as distinct from Core disturbance (coring artefacts) and Diagenesis (post-depositional chemical/redox change). This is separate from the "Additional primary soils" option in Add Layer above: that one changes the layer's KA5 code and column width for interbedded soil TYPES (e.g. mS/fS); this tab just logs the structure as an observation, at whatever depth range it occurs, without changing the layer's soil classification.

About the Munsell colours

The notations and names in this list (e.g. 10YR 6/4 — Light Yellowish Brown) follow the standard Munsell Soil Color Chart system used in pedology, geology, and archaeology — the same public reference system used across soil science and archaeological fieldwork, not a proprietary or invented scheme.

Sources:

  • Notations (hue/value/chroma codes) — Munsell Color, Munsell Soil-Color Charts (Munsell Color / X-Rite, 2009 revised edition), the standard reference used worldwide for describing soil colour in the field.
  • Descriptive chart names — this dataset is used by the R munsellinterpol package for its descriptive chart names (there called the "Ferguson Name").

The on-screen swatches are an approximate sRGB conversion for display purposes only. Monitor calibration, ambient light, and screen technology all affect how a colour renders, so these swatches are not a substitute for comparing your sample against a physical Munsell chart under standard daylight when precision matters.
